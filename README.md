# TerryXu for ComfyUI

**TerryXu** 是一个面向 ComfyUI 的个人效率工具节点包，主要用于补充保存、视频对比、H3 提示词编辑、时间轴编辑以及工作流线束整理等功能。

项目目标是把常用但原生 ComfyUI 不够顺手的操作做成更直观、更高效的节点，并尽量同时兼容普通节点模式与 Nodes 2.0。

## 安装

将仓库克隆或下载到：

```text
ComfyUI/custom_nodes/ComfyUI-TerryXu-nodes/
```

然后重启 ComfyUI。

GitHub：

```text
https://github.com/terry-xu-2077/ComfyUI-TerryXu-nodes
```

## 性能监控

顶部运行工具栏左端新增 **TerryXu 性能监控** 图标，点击打开或关闭可拖动浮窗，位置保存在当前浏览器。

- 显示 ComfyUI 服务所在电脑的整机 CPU、内存、GPU、显存占用和 GPU 温度，多显卡可切换。
- 放大的资源趋势图为主视图，CPU、内存、GPU、显存四项读数压成一行；悬停读数查看硬件与容量详情。
- 保留最近 60 次采样，横轴固定为最近 2 分钟，纵轴固定为 0–100%，两个方向均不自动拉伸；刚开始仅在右侧显示已采样部分，每两秒按需更新。
- 趋势曲线合并短促的小幅锯齿，保留明显波峰和快速负载变化；顶部实时数值及原始采样不做平滑处理。
- 线条采用圆滑连接，经过采样点且不会额外抬高波峰，缺失数据处保持断线。
- 浮窗打开时由 ComfyUI 服务端持续采样，切换浏览器标签页不中断监控，返回时自动补齐真实历史；关闭浮窗后断开监控连接，最后一个监控连接关闭时停止采样。
- NVIDIA 优先使用已安装的 NVML Python 绑定，否则尝试驱动自带的 `nvidia-smi`。无监控接口或不支持的指标显示为不可用，不影响节点运行。
- 使用本地只读接口 `/terryxu/performance` 和 `/terryxu/performance/stream`，不创建 CUDA 上下文、不上传数据；真正断连造成的采样缺口仍用断线表示。

首次更新到含此功能的版本，需要重启 ComfyUI 并刷新页面。

## 节点配色

选中节点后，点击浮动工具栏新增的**调色盘图标**，打开紧凑色板。原有颜色按钮和菜单保持不变。也可右键任意节点 → **TerryXu · 增强配色**。

- 三排圆形色块共 36 组预设，点击即上色并收起。
- 「+」展开标题、背景的取色器和 HEX 输入；「✓」应用自定义颜色，「☆」收藏组合。
- 右键节点在多选范围内时，批量给选中的节点上色。
- 可收藏、使用及删除自定义配色组合；收藏保存在当前浏览器的当前 ComfyUI 站点中。
- 配色随工作流保存；「↶」恢复默认颜色。收藏色块可右键或按 Delete 删除。

更新后刷新浏览器即可加载此功能，无需额外依赖。新增图标使用 `getSelectionToolboxCommands` 扩展接口，右键入口使用 `getNodeMenuItems`，不接管原生菜单。实际节点文字样式由 ComfyUI 主题决定，浅色配色可能降低文字可读性。

配色逻辑测试：`node --test tests/node_colors.test.mjs`。

## 节点

### TerryXu 文件保存

分类：`TerryXu/Save`

一个输入即可保存 VIDEO / IMAGE / AUDIO / STRING，并根据实际连接类型动态显示对应参数。

主要功能：

- 自动识别视频、图片、音频、文本类型。
- 根据输入类型只显示当前需要的保存参数。
- 图片、音频、视频尽量复用 ComfyUI 原生保存与编码逻辑。
- 支持精确文件名和子目录，例如 `project/shot_01`。
- 文件名既可在节点内填写，也可由外部 STRING 输入覆盖。
- 默认在文件名尾部添加 5 位序号，也可关闭序号直接覆盖同名文件。
- 文本支持多种扩展名及自定义扩展名。
- 参数使用圆角 DOM 面板显示，同时兼容普通节点模式与 Nodes 2.0。

使用方法：

1. 将 VIDEO / IMAGE / AUDIO / STRING 输出连接到节点的“内容”输入。
2. 节点会自动显示对应类型的参数。
3. 在“文件名”中设置保存名称，或将外部 STRING 接入“文件名”插槽。
4. 根据需要开启或关闭“尾部添加序号”。
5. 执行工作流即可保存到 ComfyUI 的 `output` 目录。

### TerryXu 日期格式化

分类：`TerryXu/Utils`

用于把当前日期和时间写入文本模板，方便直接连接到“文件名”等 STRING 输入。

- 默认文本模板：`%date%`
- 默认格式：`YYYYMMDDHHmmss`
- 支持直接修改格式，例如 `YYYY-MM-DD_HH-mm-ss`
- `YYYY` 年、`MM` 月、`DD` 日、`HH` 时、`mm` 分、`ss` 秒
- 仅输出“格式化文本”

---

### 🧹 TerryXu 内存清理

分类：`TerryXu/工具`

RAM、显存缓存和模型卸载拆成三个独立开关，可以串接在生成链路中，也能单独执行。

- **清理 RAM**（默认开启）：执行 Python 垃圾回收；Windows 整理当前 ComfyUI 进程的工作集，Linux 尝试 `malloc_trim`，不会整理其他进程或系统文件缓存。
- **清理显存缓存**（默认开启）：仅调用 ComfyUI 的 `soft_empty_cache()` 释放可回收显存缓存，**不会主动卸载已加载模型**。
- **卸载模型**（默认关闭）：单独调用 ComfyUI 的 `unload_all_models()`。开启后，后续再次使用 H3 / CLIP / VAE 等模型时可能需要重新加载；若还要把卸载后留下的缓存一并释放，可同时开启“清理显存缓存”。
- `anything → output` 支持任意类型与 ComfyUI List，保留输入数据及列表顺序；三个开关都关闭时只透传。
- 即使输入数据相同，工作流再次执行时仍会触发当前启用的清理操作。

注意：循环工作流中如果希望 H3 保持驻留，建议关闭“卸载模型”；是否开启 RAM/显存缓存清理再按实际显存压力决定。

### TerryXu 视频对比

分类：`TerryXu/Video`

用于同步对比两段视频，适合比较 AI 视频版本、不同参数结果或前后修改效果。

主要功能：

- A / B 两路 VIDEO 输入。
- 两段视频在同一预览区域同步播放。
- 使用竖向分割线进行 A/B 对比。
- 可拖动中间分割线查看差异。
- 底部时间轴同步控制两段视频。
- 支持播放 / 暂停和拖动定位。
- 两段视频时长不同，以较长视频作为时间轴长度。
- 较短视频播放结束后显示黑场。
- 默认循环播放。
- A / B 原视频仍可继续从节点输出。

使用方法：

1. 将两段 VIDEO 分别连接到 A、B。
2. 执行工作流生成预览。
3. 拖动中间分割线比较画面。
4. 使用底部时间轴进行同步定位和播放。

### TerryXu 分组开关

分类：`TerryXu/工作流管理`

手动选择工作流中的节点分组，并分别控制各分组内节点的启用或旁路状态。

主要功能：

- 每一行使用一体式“分组下拉菜单 + 开关 + 跳转按钮”。
- 默认显示一行未选择的分组控件；选择分组前，开关和跳转按钮保持禁用。
- 选中分组后自动在下方添加一行新的空白分组控件，不会自动列出全部分组。
- 开启时启用组内节点，关闭时旁路组内节点。
- 点击右侧箭头可直接跳转到对应分组，并按需调整画布缩放。
- 支持持续添加多个分组；已选择的分组不会在其他下拉菜单中重复出现。
- 下拉菜单重新选择空白项即可移除对应分组。
- 分组新增、删除、重命名及节点状态变化会自动同步。
- 已选择的分组与开关状态随工作流保存和恢复。
- 同时支持普通节点模式与 Nodes 2.0，并适配中文 / 英文界面。

使用方法：

1. 创建“TerryXu 分组开关”节点。
2. 在下拉菜单中选择需要控制的节点分组。
3. 使用分组右侧的开关启用或旁路组内节点。
4. 点击右侧箭头可快速定位到对应分组。
5. 使用下方新增的空白分组控件继续添加其他分组。

### TerryXu H3 提示词编辑器

分类：`TerryXu/Text`

用于可视化编写 MiniMax H3 格式提示词，同时支持图片、视频和音频参考。

主要功能：

- 输出始终为标准 H3 原始 STRING。
- 支持连接多路 IMAGE / VIDEO / AUDIO 参考素材。
- 输入 `@` 打开参考素材菜单。
- 输入 `/` 打开 H3 标签 / 命令菜单。
- 图片参考可直接显示缩略图。
- 支持 Subject / Picture / Video / Audio / Shot / Speaker / Dialogue 等标签可视化。
- 支持 `[Shot N]` 与 `(S1)` 点击切换序号。
- 支持 `<d>[Language] ...</d>` 对白编辑和语言选择。
- 支持中文 / 英文 ComfyUI 界面显示。
- 可在可视化编辑和原始 H3 文本之间切换。
- 可选连接 **TerryDirector Llama**；连接后编辑框右下角显示 ✦ AI 增强按钮，直接复用 TerryDirector 的 GGUF / H3 Skill / 自定义系统提示词与共享推理 Runtime，不在本仓库重复实现 Llama 节点。

使用方法：

1. 将需要引用的图片、视频或音频连接到参考输入。
2. 在编辑框中粘贴或编写 H3 提示词。
3. 输入 `@` 插入参考素材。
4. 输入 `/` 插入 H3 语法标签。
5. 如需 AI 增强，将 **TerryDirector Llama** 输出连接到本节点的「Llama」输入；编辑框右下角会出现 ✦。点击后增强当前 H3 原文并写回编辑器，增强过程中再次点击可请求取消。TerryDirector Llama 为 Bypassed / Never 时按钮会禁用。
6. 节点输出端得到标准 H3 原文，可直接连接后续节点。

### TerryXu H3 提示词编辑器（时间轴）

分类：`TerryXu/Text`

H3 提示词编辑器的时间轴版本，适合处理多镜头视频提示词。

主要功能：

- 以镜头时间轴方式管理 H3 `[Shot N]` 内容。
- 支持新增、删除和重新排序镜头。
- 可拖动镜头之间的接缝调整时长。
- 支持设置视频总时长。
- 当前镜头使用独立富文本编辑区。
- 与普通 H3 编辑器共用同一套标签格式化与参考菜单逻辑。
- 支持图片、视频、音频参考。
- 支持 `overall_soundscape` 和 `non_diegetic_music`。
- 最终自动编译成标准 H3 STRING。

使用方法：

1. 设置总时长。
2. 添加需要的镜头。
3. 拖动镜头块或接缝调整顺序和时长。
4. 在镜头描述中使用 `@` 插入参考素材，使用 `/` 插入 H3 标签。
5. 节点输出最终编译后的 H3 提示词。

### 🔗总线-入

分类：`TerryXu/Wire Management`

将多条不同类型的 ComfyUI 连线整理成一根 TerryXu 总线，减少复杂工作流中的连线数量。

主要功能：

- 可接入任意数量、任意类型的连接。
- 自动记录原始连接的类型、名称和顺序。
- 输出一根虚拟总线。
- 总线使用多线排线样式显示，便于和普通连接区分。
- 支持 KJNodes Get / Set 场景。

使用方法：

1. 将需要整理的多个输出连接到“添加线束”。
2. 从“总线”输出得到一根 TerryXu BUS。
3. 将 BUS 连接到“🔗总线-出”节点。

---

### 🔗总线-出

分类：`TerryXu/Wire Management`

与“🔗总线-入”配套使用，将一根 TerryXu BUS 恢复为原始多路输出。

主要功能：

- 自动恢复连接数量。
- 自动恢复连接类型。
- 自动恢复原始顺序和端口名称。
- 适合整理跨区域、跨节点组的大量工作流连线。
- 对外提供稳定的虚拟输出解析接口，TerryDirector 可跨总线追踪 Resolution Selector 等真实上游参数。

使用方法：

1. 将“🔗总线-入”的 BUS 连接到“🔗总线-出”的总线输入。
2. 节点会自动生成对应输出。
3. 从还原节点继续连接后续工作流。

---

### ⛓️‍💥总线-入 / ⛓️‍💥总线-出

分类：`TerryXu/Wire Management`

无需连接 BUS 线，通过独立的 TerryXu 频道在节点之间传递多路连接。

主要功能：

- “⛓️‍💥总线-入”接入任意数量、任意类型的连接，并在底部输入频道名称。
- “⛓️‍💥总线-出”通过底部下拉菜单选择频道，自动恢复全部输出名称、类型和顺序。
- 一个频道可供多个“⛓️‍💥总线-出”同时使用；频道改名时，已配对节点自动同步。
- 使用固定线路身份，断开某一路不会导致其他输出错位或迁移。
- 频道列表与 KJNodes Get / Set 完全隔离，双方名称不会互相混淆。
- 同时兼容普通节点模式和 Nodes 2.0，并支持工作流保存与重新加载。

使用方法：

1. 创建“⛓️‍💥总线-入”，将需要传递的输出连接到“添加线束”。
2. 在节点底部填写频道名称。
3. 创建“⛓️‍💥总线-出”，在底部下拉菜单中选择相同频道。
4. 将自动出现的输出接口连接到后续节点。

### 媒体加载器

分类：`TerryXu/媒体`

- 图片、音频、视频分为蓝、紫、绿三个独立背景区块，每区点击标题栏右侧“＋”先添加空槽位，再点击槽位选择资产；空槽位也可提前连接总线出口。
- 安装 TerryDirector 时优先复用其资产选择器；未安装时使用 ComfyUI Nodes 2.0 原生资产选择组件，支持已导入、已生成和上传。右键点击空槽位或文件名可直接使用原生选择器。
- 卡片显示类型编号、预览、文件名和移除按钮；点击文件名可更换资产，在同类型区域内拖动排序，也可聚焦卡片后按 Alt + 左/右方向键排序。
- 单一“总线”出口连接现有“总线-出”，按图片、音频、视频及各区卡片顺序展开为标准 IMAGE / AUDIO / VIDEO 出口。排序只更新各编号端口对应的资产内容，不移动端口或改变已有连线；移除已连接／被引用的资产时保留空槽位和原连线，生成时像 bypass 一样跳过该参考；点击空槽位可重新添加资产并沿用连线。未引用的资产直接移除。
- 资产路径和顺序随工作流保存；实际媒体文件仍需在打开工作流的电脑上存在。只有下游使用的媒体才会解码。

### 总线转列表

分类：`TerryXu/线束整理`

- 将媒体加载器或总线-入连接到单一“总线”输入，按总线顺序生成一个 ComfyUI 原生列表；也支持通过总线-出转接。
- 节点直接显示识别到的类型及数量，例如“图片 3”或“混合：图片 2 · 音频 1”；空槽位自动跳过。
- 同类数据的出口自动显示对应类型；混合数据使用通用列表出口，需要下游节点支持列表中的各类数据。
- 支持最多 100 个非空项；没有可用数据时自动跳过下游。
- 图片列表保留每项的原始尺寸，不合并成图片批次；普通下游节点会依次处理列表中的每项数据。
- 提供 `__terryBusListEntries()` 资产追踪接口。Flow 引用菜单的兼容补丁见 [compat/README.md](compat/README.md)；不会改变混合列表的实际输出。
- 媒体加载器也可直接接入 H3 编辑器的“参考 · 多路输入”；引用菜单和可视化标签按卡片顺序显示真实文件及缩略图，执行时按资产编号提取媒体，空槽位自动跳过。
